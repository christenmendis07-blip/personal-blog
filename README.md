# Christen Mendis — Software Developer Portfolio

A sleek, responsive, and modern single-page personal portfolio website for **Christen Mendis**, Computer Science Student & Aspiring Software Developer. Built with semantic **HTML5**, **CSS3**, and **vanilla JavaScript**.

Designed with dark mode by default, a light mode toggle, subtle interactive animations, and clean modular code.

---

## ✨ Features

- **Theme Switching**: Dark mode default with a smooth light-mode toggle button and `localStorage` persistence.
- **Interactive Hero Canvas**: Lightweight ambient particle and constellation background that responds smoothly to mouse interactions.
- **Fluid Scroll Animations**: Fade-in and scroll reveals powered by the native `IntersectionObserver` API.
- **Selected Projects**:
  - **Ascend**: Productivity and digital-discipline platform for students built with Flutter and Dart.
  - **Graphics Editor**: Menu-driven terminal graphics editor in C with Bresenham's line algorithm and math plotting.
- **Realistic Student Skills**: Categorized technical toolkit covering Programming (C, Java, Python, Dart), Web (HTML, CSS, JavaScript), Databases (MySQL, SQLite), and Tools (Git, GitHub, VS Code).
- **Academic Background**: Education entry highlighting B.Tech in Computer Science at REVA University (2025 – 2029).
- **Interactive Contact Section**: Contact channels with click-to-copy email feedback, verified social links (GitHub, LinkedIn), and front-end validated contact form.
- **Responsive Design**: Mobile-friendly hamburger navigation and touch-optimized layout across desktop, tablet, and mobile devices.

## 🚀 Quick Start

### 1. View Directly

Open `index.html` directly in any modern web browser (Chrome, Safari, Firefox, Edge).

### 2. Or Run a Local Server

Run a quick local web server:

```bash
# Using Python:
python3 -m http.server 8000

# Or using Node:
npx serve .
```

Then open `http://localhost:8000` in your browser.
